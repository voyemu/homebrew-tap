# Voyemu Homebrew tap

Install the [Voyemu 1.0.0-beta1 prerelease](https://github.com/voyemu/voyemu/releases/tag/v1.0.0-beta1) on a Mac with Apple Silicon and macOS 13 or later.

```sh
brew install voyemu/tap/voyemu
voyemu --version
```

Homebrew keeps Voyemu's tools, firmware inputs and prepared machines in `$(brew --prefix)/var/voyemu`.
